3. Database Handover (Supabase)

The system stores citizen complaints, daily work logs (दैनिक कार्य), ward stats, and admin actions on Supabase PostgreSQL.

Option A: Transfer Project Ownership (Zero Downtime — Recommended)

  1. Log into the developer Supabase dashboard (https://supabase.com/dashboard).
  2. Select project ward9.
  3. Navigate to Project Settings → General → Members / Team Settings.
  4. Click Invite Member → Enter client's registered Supabase email → Select Owner role.
  5. Once the client accepts the invitation, the client removes the developer's email from the organization. Ownership is 100% transferred.

Option B: Fresh Setup on Client's Supabase Account

  1. Client creates a new project on their Supabase dashboard named janseva09.
  2. Open the SQL Editor in the new project.
  3. Copy and execute the entire contents of supabase-schema.sql (provided in the repository root). This builds all tables, indexes, and row policies.
  4. Retrieve the following credentials from Project Settings → API:
    • Project URL (e.g., https://<client-project>.supabase.co)
    • anon / public key
    • service_role key (Secret)

4. Web Hosting & Server Handover (Vercel)

The web portal runs on Next.js 16 and is hosted at https://janseva09.vercel.app (or client custom domain).

Step-by-Step Vercel Transfer:

  1. Project Transfer via Vercel: In Vercel Project Settings → Advanced → Transfer Project → Enter client's Vercel username.
  2. Alternative (Import via Client GitHub):
    • After the client receives the GitHub repository, log into client Vercel.
    • Click Add New... → Project → Import janseva09.
    • Framework Preset: Next.js (automatically detected).
  3. Configuring Environment Variables in Vercel:
    Add the following keys in Project Settings → Environment Variables:

NEXT_PUBLIC_SUPABASE_URL Client Supabase Project URL Database REST endpoint
NEXT_PUBLIC_SUPABASE_ANON_KEY Client Supabase Anon Key Public browser database key

SUPABASE_SECRET_KEY Client Service Role Key Fallback backend secret key

5. Email & SMTP Configuration (Google App Password)

Crucial Step: Removing Personal Email
All outgoing citizen emails (complaint registration code, resolution confirmation) and Sanchalak alerts must be migrated to the client's Google Account.
  1. Log into the client's official Google account.
  2. Navigate to Manage Your Google Account → Security.
  3. Ensure 2-Step Verification is switched ON.
  4. Under 2-Step Verification, scroll down to App passwords.
  5. Create an App Password with name: JanSeva Portal.
  6. Google will generate a 16-letter password (e.g. abcd efgh ijkl mnop).
  7. Set this 16-character string as SMTP_PASS in Vercel environment variables.

7. Android Mobile App (APK) Handover

The mobile app is built with Capacitor. It functions as a native Android container loading the secure production web application, ensuring instant real-time synchronization with website updates.

App Configuration Summary
  • App Package ID: com.ward09.jodhpur
  • App Name: जनसेवा 09
  • Icon Assets: Official Ward 9 icon generated across all Android densities (mipmap-mdpi to mipmap-xxxhdpi) with adaptive icon safe-zone margins.
  • Production URL: Configured in capacitor.config.ts pointing to the live portal.

How to Build Future APK Releases:

# 1. Navigate to android directory
cd e:\ward9\android

# 2. Build Debug APK (for instant testing)
.\gradlew assembleDebug
# Output: android\app\build\outputs\apk\debug\app-debug.apk

# 3. Build Release APK (for production / distribution)
.\gradlew assembleRelease
# Output: android\app\build\outputs\apk\release\app-release-unsigned.apk
